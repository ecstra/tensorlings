## Decision

Every tensorlings exercise asks for code to write or fix and is passed by tests. Seeing a model fail happens inside the exercise that builds the fix.

## Alternatives

Prediction exercises, where the learner types a guessed number and a reason before a run. The research on predicting first is real, but the owner read them as a quiz with nothing to build and rejected them.

## Consequences

The "why it exists" step of each block is an exercise that builds the failing model and the fixed one side by side.
