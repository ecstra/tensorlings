The owner wants every lesson in plain, natural English, with each term explained where it first appears, a concrete example with real numbers before any general idea, and nothing that assumes they remember deep learning basics. They rejected lessons that read as confusing or as filler, prediction only exercises, and lessons hidden in README files. In the second round they said the lessons "sound like AI" and that a task "just gave the answer and asked me to type it". They also want the screen to label every piece, never a dot between parts, and they cannot make the window taller, so everything must scroll.

This matters because two versions of the course failed on exactly these points, and the owner wants to go through the whole course without asking for rewrites.

To apply it, hold every lesson to the writing rules and the task rules in the course design doc, run the lesson lint and a beginner reader review before anything reaches the owner, and keep every exercise as code.
